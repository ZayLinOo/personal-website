# Personal Website

Source code for Zay Lin Oo's personal website.

## Local Development

```powershell
npm.cmd install
npm.cmd run dev
```

On Windows, you can also double-click `start-local.cmd` or run it from PowerShell:

```powershell
.\start-local.cmd
```

## Build

```powershell
npm.cmd run build
```

## Repository

- GitHub: https://github.com/ZayLinOo/personal-website
- Default branch: `main`
