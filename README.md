# Personal Website

Source code for Zay Lin Oo's personal website.

## Local Development

```powershell
npm.cmd install
npm.cmd run dev
```

On Windows, you can also double-click `start-local.cmd` or run it from PowerShell:

```powershell
.\start-local.cmd
```

## Build

```powershell
npm.cmd run build
```

## Hostinger Deployment

Use these settings when deploying this Vite site from Git:

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

If uploading manually, upload the contents of `dist/`, not the whole project folder.

## Repository

- GitHub: https://github.com/ZayLinOo/personal-website
